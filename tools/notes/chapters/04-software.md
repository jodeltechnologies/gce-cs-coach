# Software

#### 4.0. Introduction

Computers require instructions to perform tasks. These instructions are provided by the programs stored in them. The collection of computer programs that provide the instructions that tell the computer what to do is called software. Software that makes up the intangible components of the computer system has two major categories namely system software and application software.

#### 3.1. System Software

System software is designed to operate computer hardware and provide a platform (environment) for running application software. Systems software functions as a bridge between computer system hardware and application software. Examples of system software include operating systems, utility programs, device drivers and language translators.

##### 3.1.1. Operating Systems

An operating system is software that manages the hardware and software resources of a computer, and serves as interface between the computer user and the computer. The operating system is the first program installed computer without which the computer cannot work. Operating systems are every computing device such as desktops, smartphones, tablets, supercomputers and mainframe computers. Examples of OS include: Microsoft Windows (95, 98, 2000, XP, vista, 7, 8, 10, 11), Macintosh operating system (Mac OS), Linux (Ubuntu), UNIX, Microsoft disk operating system (MS- DOS), Android, Windows Mobile, and iPhone operating system (iOS).

- Types of Operating Systems:

- Single User OS: A single user OS allows only one user to access the computer at a time. Single user OS can be split into two: single user, single tasking and single user, multitasking. A single user, single tasking OS deals with only one user at a time, running only one user program (task). Examples are MS DOS, and Palm OS. A single user, multitasking OS deals with only one user at a time, running many applications (or programs) at the same time. Examples are Windows, Linux, Mac OS, and Android OS.

- Multi User OS: A multiuser OS allows many users to access the computer at a time. All multiuser operating systems are multitasking. Examples are UNIX and VMS (virtual Memory system) operating system.

- Multiprogramming OS: Multiprogramming is the ability to keep several programs in memory at the same time. A multiprogramming OS allows several programs to be kept in memory at the same time and decides which can be executed at a moment.

- Multitasking OS: Multitasking is the ability to execute more than one program (task) simultaneously on a single CPU. An OS that allows a user to perform more than one computer task at a time on a single CPU is a multitasking OS. In reality, no two tasks can be executed at the same time on a single processor. Actually, the CPU switches from one task to the next task so quickly that it appears as if all the tasks are executing at the same time. Working on the Internet while listening to music is multitasking. Windows XP and Mac OS are examples of single user, multitasking operating systems.

- Multiprocessing OS: Multiprocessing is the ability to execute more than one task on multiple CPUs at the same time. A multiprocessing OS allows more than one task to run on multiple CPUs simultaneously.

- Batch OS: Batch processing is a processing method in which similar data in a

- Real-Time OS: Real-time processing is a processing method in which data is processed immediately it is entered into the system. A RTOS allows data to be processed immediately with very precise timing and a high degree of reliability.

- OS Functions: An operating system executes many functions to operate the computer system efficiently. Among them, five essential functions are memory management, task management, file management, user interface and security.

- Memory management: This is the function of an operating system that handles primary memory (RAM). It involves controlling and coordinating the usage of primary memory by different programs, assigning portions called blocks to various running programs to optimize overall system performance.

- Task management: This is the function of an operating system that controls the running of many tasks. The OS schedules, controls, and monitors tasks submitted for execution to ensure the most efficient processing.

- File management: This is the function of an operating system that manages data files. An operating system contains file management programs that provide the ability to create, delete, modify, copy and move files of data. The way an operating system organizes information into files is called the file system.

- Security management: This is the function of the operating system that provides a means for safeguarding system resources from unauthorized users and protection of one user's resources from other users of the system. Popular operating systems offer security features through incorporation of the following:

- Login name.

- Login password.

- Read/write access file permissions.

- Encryption of data

- Virus protection software layers

- USER INTERFACE: The operating system provides an environment for running application programs.

##### 3.2.1. Utility Software

Utility software is software that is used to enhance the operating system, or in some other way improve the usefulness of the system. It is designed to help configure the system, analyze how it is working, and optimize it to improve its efficiency. Most major operating systems come with several pre- installed utilities. Examples of utility software include: disk defragmenters, backup utilities, disk compression utilities, disk cleaners, disk formatters and virus checkers.

- Disk defragmenter: A program that locates the noncontiguous fragments of a file on disk and rearranges them into fewer fragments or the whole file to increase efficiency.

- Compression utility: A utility program that is used to compress and decompress a file. Compression reduces the size of a file making the file to take up little space on disk.

- Disk cleaner: A program that removes temporary files that are unnecessary to computer operation, increasing free storage space on the disk.

- Disk partition utility: A utility program that is used to divide an individual drive into multiple logical drives, each with its own file system which can be treated by the operating system as an individual drive.

- Backup utility: A utility program that is used to make copies of all data stored on a disk, and restore either the entire disk (e.g. in an event of disk failure) or selected files (e.g. in an event of accidental deletion).

- Virus checkers: A utility program that prevents, detects and removes malicious programs from the system. These malicious programs are called viruses. To prevent your computer against viruses, you should install an antivirus and update it regularly. Also make sure you scan any files from external devices like flash drives, before you open them.

##### 3.2.3. Device Drivers

A device driver is software that allows interaction between the operating system and a hardware device. Without an appropriate device driver the operating system cannot communicate with a device, rendering the device useless. Installation of device drivers usually happens automatically when hardware is connected, or from a CD provided with the device. Sometimes a device driver needs to be updated to stay functional.

##### 3.2.4. Programming Software

Programming software are programs that are used to produce other software. They are compilers, interpreters, assemblers and debuggers.

- Compiler: A program that translates an entire program written in high-level language into an object code that is in machine language. Machine language is the language the computer understands. It is made of 0s and 1s.

- Interpreter: A program that translates and executes program instructions written in high-level language one line at a time. The interpreter translates one instruction and executes it before moving to the next instruction.

- Assembler: A program that translates an assembly language program into executable machine language.

- Debugger: A program that is used to detect and remove bugs from a computer program. A bug is an en error in a program.

#### 3.2. Application Software

Application software is software designed to carry out specific tasks for the user. They are used to carry out productive work like typing a letter, designing an invitation card, surfing the Internet, listening to music or watching a movie. Application software cannot run on their own, they perform in an environment which is created by the operating system. Application software can be divided into general-purpose software, specialist software and custom-written software.

##### 3.2.1. General-purpose software

General-purpose software is software that can perform many different tasks. It is not limited to one particular function. It is also called generic software and can be found off-the-shelf. This means that they are ready-made and can be bought from the market. Different types of general- purpose application software exist:

- Word processor: used to create, edit and format text documents such as fliers, letters, reports and memos. Examples of word processors are Microsoft Word, Lotus Word Pro and WordPerfect.

- Spreadsheet: used for tasks that involve calculations or for the production of graphs and charts. Examples are Microsoft Excel, Lotus 123, iWork Numbers, and LibreOffice Calc.

- Desktop publishing software: used to produce quality publications such as posters, books, newsletters, newspapers and magazines. Examples are Microsoft Publisher, Adobe InDesign, PageMaker and PagePlus.

- Presentation software: used to create slide shows and presentations which can be viewed on-screen or projector. Examples are Microsoft PowerPoint, Lotus Freelance, Adobe Acrobat and SoftMaker.

- Database software: used to create and manage databases. Examples of database applications are Microsoft Access, Lotus Approach, FileMaker Pro and Oracle.

- Graphics software: used to create and manipulate pictures or images. Examples are Adobe Photoshop, Microsoft Picture Manager, Pizap and Picasa.

##### 3.2.2. Special-purpose software

Special-purpose or specialist software is designed to perform a single very specific task. Accountancy software is a good example of this kind of sofware. A camera application is also an example of a special purpose software. Specialist software can also be found off-the-shelf.

##### 3.2.3. Custom-written software

Custom-written software is designed to a particular user's requirements or needs and is therefore not available off-the- shelf. It is also called bespoke or tailor-made software as it is tailored to the exact requirements of the user or organization.

##### 3.2.4. Integrated software

An integrated software package is software that consists of multiple application software bundled together as a single software. They usually have related functions, features and user interfaces, and may be able to interact with each other. Examples are Microsoft Office, OpenOffice, Lotus SmartSuite, and LibreOffice.

#### 3.3. Attributes of Software

The attributes of software are the properties or characteristics that good software should have. These include:

- Usability: It refers to the ease with which software can be learnt and used. Software that is easy to learn and use is said to be user-friendly

- Reliability: It refers to the ability of a software to continue to run in the expected way over time.

- Portability: It refers to the ability of a software to be used on different platforms (operating systems) other than the one in which it was created.

- Maintainability: It refers to the ease with which software can be changed in order to meet with changing needs.

- Robustness: It refers to the ability of a software product to cope with unusual situations.

- Efficiency: It refers to the ability of a software product to do the required processing on least amount of hardware.

#### 3.4. Software Distribution Licenses

Software can be distributed as public domain software, freeware, shareware, open source and all rights reserved (commercial) software.

- Public domain: Public domain software has no owner and is not protected by copyright law. It was either created with public funds or the ownership was forfeited by the creator. Public domain software can be copied, sold and/or modified. It is often of poor quality.

- Freeware: Freeware is copyrighted software that is licensed to be copied and distributed without charge. Freeware is free but it is still under the owner's control. Examples are Eudora and Netscape.

- Shareware: Shareware is copyrighted software that allows you to use it for a trial period but you must pay a registration fee to the owner for permanent use. Some software developers offer a shareware version of their program with a built-in expiration date (after 30 days, the user can no longer get access to the program) while Other shareware (sometimes called liteware) is offered with certain capabilities disabled as an enticement to buy the complete version of the program. Purchasing the right to use the software may also get you a version with more powerful features and published documentation.

- Open source: Open source software is software whose source code is published so that a variety of people can add contribution. "Source code" is the part of software that most computer users don't ever see; it's the code computer programmers can manipulate to change how a piece of software – a "program" or "application" – works. Examples are Linux OS, MySQL, Mozilla and OpenOffice

- All Rights Reserved: All rights reserved software is software that must be used by the purchaser according to the exact details spelt out in the license agreement.

#### 3.5. Human Computer Interface

Working on a computer, a user has to interact with the computer. The means of communication or interaction between the user and the computer is called user interface. Different software provide different types of user interfaces.

##### 3.5.1. Command line Interface (CLI)

A command line interface allows the user to interact with the computer by typing the commands for computer to execute. The user types the commands in a specified format using a command prompt. Command line interface is also called text based user interface. Examples of systems which provide a command line interface are Microsoft disk operating system (MS DOS) and basic UNIX.

- Advantagesof CLI – It occupies and uses little memory space – It does not require high processing power – It is generally fast and quick to operate for experts

- Disadvantages of CLI – The user has to remember the name and format of commands – It is good only for experts and not for novice users (it is not user friendly)

##### 3.5.2. Menu Driven Interface

A menu driven interface (MDI) allows the user to interact with the computer by selecting options from a list. Menu driven interface is also called graphical character based user interface. Examples of menu driven interface are found in mobile phones and cashpoint machines (ATMs) in banks.

- Advantages of MDI – It is easy to use for beginners as they don't need to memorize commands – It does not require high processing power

- Disadvantagesof CLI – It occupies much space in memory as compared to CLI – It is less flexible as user can only execute actions that are listed – It may be time consuming to scroll down a very long list of menu items

##### 3.5.3. Graphical User Interface (GUI)

A graphical user interface (GUI) allows a user to interact with the computer through graphical items such as icons, menus, dialog boxes, etc. Here, the user mostly makes use of pointing devices, like the mouse trackball and joystick, to point and click on these graphical items. Features of GUI are windows, icons, menus and pointers. As such, GUI is also known as WIMP (Windows, Icon, Menus, Pointers) interface. Examples of GUI are Windows, Mac OS and Linux.

- Advantages of GUI – It is user friendly or easy to use for beginners – One does not need to memorize commands – It groups many commands in a single click – It can be customized to suite a user's preference

- Disadvantages of GUI – It requires a lot of memory space to store the graphics – It requires high processing power. It can cause machines with low processing power to be slow.

##### 3.5.4. Voice Recognition Interface

A voice recognition interface allows the user to interact with the computer by giving verbal commands. The user communicates with the computer through natural language. They are also called natural language interface.

- Advantages of VRI – It is hands free – It can be used by people with disabilities

- Advantages of VRI – It does not understand all languages – It can interpret wrongly
